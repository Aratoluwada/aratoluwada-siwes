# SIWES Technical Defense — Aratoluwada Toluwade

A single-page technical presentation website created for my Students Industrial Work Experience Scheme (SIWES) defense.

## About

This website documents my 12-week SIWES experience as a Mechatronics Engineering student at the Federal University of Agriculture, Abeokuta (FUNAAB).

The training covered four major areas:

- Software Engineering
- CAD / 3D Modelling
- Solar Installation
- GridWatch IoT Hardware Project

## Featured Project

### GridWatch

GridWatch is an IoT-based solar monitoring system developed using an ESP32 and connected technologies.

**Technologies used:**

- C++
- ESP32
- JavaScript
- HTML
- CSS
- MQTT

## Website Features

- Neo-brutalist engineering-themed interface
- Responsive design
- SIWES training gallery
- Image lightbox
- Technical project showcase
- Downloadable technical report
- Downloadable presentation slides
- Vanilla JavaScript scroll-reveal animations

## Tech Stack

This website was built entirely with:

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or build tools were used.
